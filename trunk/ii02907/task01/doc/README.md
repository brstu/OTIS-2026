## 1. Вариант задания

Вариант 5. Реализованы три математические модели динамических систем:

- Model 1.5 — линейная модель с задержкой;
- Model 2.7 — модель с релейным элементом и гистерезисом;
- Model 3.9 — модель с нелинейной функцией `tanh`.

## 2. Цель работы

Реализовать заданные модели на C++ с использованием объектно-ориентированного подхода и исследовать их поведение при различных входных воздействиях. Результаты моделирования сохраняются в CSV-файлы и могут быть представлены в виде графиков.

## 3. Математические модели

### 3.1. Model 1.5

Модель описывается разностным уравнением:

`y[n+1] = a1*y[n] + a2*y[n-k] + b*u[n]`

где `a1`, `a2` и `b` — коэффициенты модели, `k` — величина задержки, `u[n]` — входной сигнал, `y[n]` — выход системы.

В реализации задержка должна быть не меньше одного шага. Если требуемое значение отсутствует в истории моделирования, вместо него используется ноль.

### 3.2. Model 2.7

Модель использует релейный элемент с порогом `epsilon`. Значение релейного сигнала определяется входом:

- при `u > epsilon` реле принимает значение `+1`;
- при `u < -epsilon` реле принимает значение `-1`;
- внутри пороговой полосы значение определяется по предыдущему выходу модели: положительный выход даёт `+1`, отрицательный — `-1`, а выход внутри полосы — `0`.

После определения релейного сигнала вычисляется выход:

`y[n+1] = a*y[n] + b*relay`

Параметр `epsilon` должен быть неотрицательным.

### 3.3. Model 3.9

Модель описывается дифференциальным уравнением:

`dy/dt = b*tanh(u)`

Для численного расчёта используется явный метод Эйлера:

`y[n+1] = y[n] + dt*b*tanh(u[n])`

Здесь `dt` — шаг моделирования, `b` — коэффициент модели. Шаг `dt` должен быть положительным.

## 4. Входные воздействия

Для каждой модели выполняется расчёт при трёх видах входного сигнала:

- **Постоянный:** `u[n] = A`.
- **Импульсный:** `u[0] = A`, при `n > 0` — `u[n] = 0`.
- **Гармонический:** `u[n] = A*sin(n)`.

Здесь `A` — амплитуда сигнала, `n` — номер шага моделирования.

### Объектно-ориентированная организация

Базовый класс `Model` задаёт общий интерфейс для моделей. Конкретные классы `Model15`, `Model27` и `Model39` реализуют собственные алгоритмы расчёта следующего значения выхода.

В `main.cpp` создаются объекты моделей, задаются параметры моделирования и выполняются расчёты для каждого входного сигнала. Результаты записываются в CSV-файлы.

## 6. Сборка и запуск

Для сборки необходимы CMake и совместимый компилятор C++ с поддержкой C++17.

В Windows из корневой папки проекта (`trunk/ii02907/task01`) можно запустить `build.bat` для сборки программы или `run.bat` для сборки и последующего запуска. Исполняемый файл создаётся в каталоге `build`.

Запускать программу рекомендуется из корневой папки проекта, поскольку CSV-файлы с результатами сохраняются в текущем рабочем каталоге.

Альтернативно команды можно выполнить вручную из папки `trunk/ii02907/task01`:

```bash
cmake -S . -B build
cmake --build build --config Release
```

После успешной сборки запустить исполняемый файл:

```bash
./build/Release/task_01.exe
```

Если файл находится непосредственно в `build`, использовать:

```bash
./build/task_01.exe
```

Программа выводит результаты в консоль и создаёт девять CSV-файлов — по одному для каждой комбинации модели и входного сигнала.

## 7. Построение графиков

Для построения графиков используется Python и библиотека `matplotlib`.

Из папки `trunk/ii02907/task01` установить зависимость:

```bash
python -m pip install -r requirements.txt
```

После запуска программы, создавшей CSV-файлы, выполнить:

```bash
python plot.py
```

Скрипт читает данные из CSV и отображает графики зависимости выхода модели от времени. По умолчанию используются столбцы `tau` и `y`.
Скрипт `plot.py` читает CSV-файлы из корневой папки проекта и сохраняет девять графиков в папку `doc/`.

## 8. Результаты моделирования

Для каждой модели рассчитываются три варианта реакции системы:

- при постоянном входном сигнале;
- при импульсном входном сигнале;
- при гармоническом входном сигнале.

Результаты сохраняются в следующих файлах:

| Модель | Постоянный сигнал | Импульсный сигнал | Гармонический сигнал |
|---|---|---|---|
| Model 1.5 | `model15_constant.csv` | `model15_impulse.csv` | `model15_harmonic.csv` |
| Model 2.7 | `model27_constant.csv` | `model27_impulse.csv` | `model27_harmonic.csv` |
| Model 3.9 | `model39_constant.csv` | `model39_impulse.csv` | `model39_harmonic.csv` |

Каждый CSV-файл содержит столбцы `step`, `tau`, `u`, `y`: номер шага, время, входное воздействие и выход модели соответственно. Изображения графиков сохраняются в папке `doc/` скриптом `plot.py`.

Коэффициенты моделей также заданы в исходном коде. Если в методических указаниях предусмотрены конкретные значения, их необходимо установить перед окончательным исследованием.
