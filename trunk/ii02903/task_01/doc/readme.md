## Вариант 3

**Линейная модель 1.3:**  
\[ y[\tau+1] = a_1 y[\tau] + a_2 y[\tau-1] + b \cdot u[\tau] \]

**Нелинейная модель 2.5:**  
\[ y[\tau+1] = a \cdot y[\tau] + b \cdot \operatorname{sign}(u[\tau]) \cdot \bigl(1 - e^{-|u[\tau]|}\bigr) \]

**Дифференциальная модель 3.7:**  
\[ \frac{dy}{dt} = -e^{a \cdot y} + b \cdot u \]  
(решается методом Эйлера с шагом \(dt\))

## Описание программы

Для выполнения задания использованы принципы объектно-ориентированного программирования.

Создан **абстрактный базовый класс `Model`** с чисто виртуальными методами:
- `step(double u)` — расчёт следующего значения выходной величины;
- `reset()` — сброс внутреннего состояния модели.

Конкретные модели реализованы в классах-наследниках:
- `LinearModel` — линейная модель 1.3 + метод `isStable()` для проверки устойчивости;
- `NonlinearModel` — нелинейная модель 2.5;
- `DifferentialModel` — дифференциальная модель 3.7 (метод Эйлера).

Программа позволяет пользователю задать:
- количество итераций \(n\);
- коэффициенты каждой модели.

Результаты сохраняются в `.csv` файлы (столбцы: \(\tau\), \(u\), \(y\)).

С помощью **gnuplot** строятся графики (`.png`).

### Входные воздействия
1. **Ступенчатое:** \( u_\tau = 1 \)
2. **Импульсное:** \( u_0 = 1 \), \( u_{\tau>0} = 0 \)
3. **Гармоническое:** \( u_\tau = \sin(\tau) \)

### Проверка устойчивости (Advanced)
Для линейной модели решается характеристическое уравнение  
\[ z^2 - a_1 z - a_2 = 0 \]  
и проверяется, что модули корней меньше 1. При неустойчивости выводится предупреждение.

## Сборка и запуск

1. Сборка выполняется файлом **`build.bat`** (используется CMake + Visual Studio).
2. Запуск — через **`run.bat`**.

> **Важно:** прямой запуск `.exe` из папки `build` может работать некорректно, т.к. gnuplot-скрипты лежат рядом с исходниками.
