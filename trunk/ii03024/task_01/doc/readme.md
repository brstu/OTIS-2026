## Вариант 26

* **Линейная модель:** Model 11
* **Нелинейная модель:** Model 28
* **Дифференциальное уравнение:** Model 36

В данной лабораторной работе разработана консольная программа на языке C++ для моделирования динамики управляемого объекта (температуры объекта) под воздействием различных типов входных сигналов.

**В программе реализованы три модели:**

* **Model 11 (Линейная модель)**
* **Model 28 (Нелинейная модель)**
* **Model 36 (Дифференциальная модель)**

**Для каждой модели поддерживается три типа входного сигнала $u(\tau)$:**
- Ступенчатый
- Импульсный
- Гармонический

Пользователь в интерактивном режиме вводит параметры выбранной модели, задает амплитуду входного сигнала $A$ и число шагов моделирования $n$.

---

## Архитектурное решение

В проекте применен ООП-подход на основе полиморфизма. Создан абстрактный базовый класс `Model`, определяющий единый интерфейс для всех математических моделей:
- Хранение выходного значения `y`
- Чисто виртуальная функция `nextStep(double u, double dt)` для вычисления следующего состояния
- Виртуальная функция `getName()` для получения названия модели

От класса `Model` наследуются специализированные классы:
- `Model11` — реализует линейную дискретную модель
- `Model28` — реализует нелинейную модель
- `Model36` — реализует численный расчет дифференциальной модели

После выполнения всех шагов расчета программа:
1. Выводит результатирующую таблицу $(\tau, u, y)$ в консоль.
2. Автоматически сохраняет данные в CSV-файл (например, `Model11_Step.csv`).
3. Генерирует временный скрипт Gnuplot и **автоматически визуализирует график** изменения выходной величины $y(\tau)$.
