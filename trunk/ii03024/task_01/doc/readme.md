## Вариант 26

- Линейная модель — **Model 11**
- Нелинейная модель — **Model 28**
- Дифференциальное уравнение — **Model 36**

## Реализованные модели

### Model 11 — линейная модель

Для моделирования используется разностное уравнение:

$$y(t+1) = a_1 \cdot y(t) + a_2 \cdot y(t-1) + b \cdot u(t)$$

где:
- $y(t)$ — текущее значение выходного сигнала;
- $y(t-1)$ — предыдущее значение выходного сигнала;
- $u(t)$ — входное воздействие;
- $a_1, a_2, b$ — коэффициенты модели.

На каждом шаге вычисляется новое значение $y(t+1)$.

### Model 28 — нелинейная модель

Нелинейная модель задаётся выражением:

$$y(t+1) = a \cdot y(t) + b \cdot \text{sign}(u(t)) \cdot (1 - \exp(-|u(t)|))$$

В данной модели используется функция знака:

$$\text{sign}(u) = \begin{cases} 1, & \text{если } u > 0 \\ -1, & \text{если } u < 0 \\ 0, & \text{если } u = 0 \end{cases}$$

Нелинейность модели определяется выражением $1 - \exp(-|u(t)|)$, где $a$ и $b$ являются коэффициентами модели.

### Model 36 — дифференциальная модель

Дифференциальное уравнение имеет вид:

$$\frac{dy}{dt} = -\exp(a) \cdot y + b \cdot u$$

Для численного решения используется метод Эйлера.

Формула расчёта:

$$y(t+1) = y(t) + dt \cdot (-\exp(a) \cdot y(t) + b \cdot u(t))$$

где:
- $dt$ — шаг интегрирования;
- $a, b$ — коэффициенты модели;
- $u(t)$ — входное воздействие;
- $y(t)$ — текущее значение выходной величины.

Метод Эйлера позволяет заменить дифференциальное уравнение последовательностью вычислений на отдельных временных шагах.

## Входные воздействия

Для исследования моделей были реализованы три вида входных воздействий.

### 1. Ступенчатое воздействие

При ступенчатом воздействии значение входного сигнала постоянно:

$$u(t) = A$$

где $A$ — заданная амплитуда.

Такое воздействие позволяет исследовать переходный процесс системы при постоянном входном сигнале.

### 2. Импульсное воздействие

Для импульсного воздействия используется:

$$u(0) = A, \quad u(t > 0) = 0$$

То есть сигнал имеет заданное значение только на первом временном шаге, после чего становится равным нулю.

### 3. Гармоническое воздействие

Гармоническое воздействие задаётся формулой:

$$u(t) = A \cdot \sin(t)$$

где $A$ — амплитуда гармонического сигнала.

Такой тип воздействия позволяет исследовать реакцию системы на периодически изменяющийся входной сигнал.

## Объектно-ориентированная реализация

Для реализации моделей был использован объектно-ориентированный подход.

Создан абстрактный базовый класс `Model`, содержащий виртуальный метод `calculateNext()`. Данный метод отвечает за вычисление следующего значения выходного сигнала.

От базового класса наследуются три специализированных класса:

- `Model11` — линейная модель;
- `Model28` — нелинейная модель;
- `Model36` — модель дифференциального уравнения.

Каждый дочерний класс реализует собственную формулу вычисления.

Такой подход позволяет работать с различными моделями через общий интерфейс базового класса.

## Работа программы

После запуска программы пользователю предлагается выбрать модель для исследования.

Далее вводятся необходимые параметры модели и выбирается тип входного воздействия.

Программа позволяет:

- выбрать одну из трёх моделей;
- ввести коэффициенты модели;
- выбрать тип входного воздействия;
- задать амплитуду сигнала;
- задать количество временных шагов;
- выполнить моделирование;
- вывести полученные значения в консоль;
- использовать полученные данные для построения графика.

## Сборка программы

На Windows запуск сборки осуществляется с помощью файла `build.bat`.
