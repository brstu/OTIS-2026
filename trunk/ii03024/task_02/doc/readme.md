## Анализ устойчивости модели 1.1

Модель: $y_{\tau+1} = a \cdot y_\tau + b \cdot u_\tau$.

Применим Z-преобразование: $zY(z) = aY(z) + bU(z)$, откуда передаточная функция $W(z) = \dfrac{b}{z - a}$.

Характеристическое уравнение: $z - a = 0$, единственный корень $z = a$.

| Положение корня | Условие | Поведение |
| :--- | :---: | :--- |
| внутри единичного круга | $\lvert a \rvert < 1$ | устойчива, процесс затухает |
| на единичной окружности | $\lvert a \rvert = 1$ | граница устойчивости, процесс не затухает |
| вне единичного круга | $\lvert a \rvert > 1$ | неустойчива, процесс расходится |

Реализация — класс `StabilityAnalyzer` (`src/StabilityAnalyzer.*`):

- `characteristicRoot(a)` — корень характеристического уравнения;
- `classify(a)` — `Stable` / `Marginal` / `Unstable` (граница определяется с допуском `1e-9`, `NaN` и `inf` считаются неустойчивыми);
- `isStable(a)` — `true` только при $\lvert a \rvert < 1$;
- `warningMessage(a)`, `warnIfUnstable(a, out)` — текст предупреждения / вывод в поток;
- `requireStable(a)` — бросает `std::domain_error`, если система не устойчива.

В `main.cpp` для модели 1.1 предупреждение выводится в консоль **до начала симуляции**.
