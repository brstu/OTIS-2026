Объектом тестирования является математическое ядро программы, разработанной в ЛР1. В рамках данной работы были выбраны следующие модели:

## 4. Теоретическая часть: Анализ устойчивости

Устойчивость дискретной системы означает, что при отсутствии внешних возмущений ее выход с течением времени стремится к нулю (или к установившемуся значению). Для линейных дискретных моделей устойчивость определяется корнями характеристического уравнения: система устойчива, если все корни лежат **строго внутри единичной окружности** на Z-плоскости (т.е. их модуль \(|z| < 1\)).

### 4.1. Model 1.10 и Model 2.5
Уравнение: \(y_{t+1} = a_1 y_t + \dots\)
Характеристическое уравнение: \(z - a_1 = 0 \Rightarrow z = a_1\).
Условие устойчивости: **\(|a_1| < 1\)**.

### 4.2. Model 3.10 (метод Эйлера)
Уравнение: \(y_{t+1} = y_t + dt \cdot (-a y_t + b + u)\).
Характеристическое уравнение: \(z - (1 - a \cdot dt) = 0 \Rightarrow z = 1 - a \cdot dt\).
Условие устойчивости: **\(|1 - a \cdot dt| < 1\)**.

## 5. Ручные пересчеты и тестовые сценарии

Все эталонные значения в тестах были получены предварительным ручным расчетом по формулам моделей.

### 5.1. Model 1.10 (Правильность значений)
Уравнение: \(y_{t+1} = a_1 y_t + b_1 u_t + b_2 u_{t-2}\).
При \(a_1=0.8, b_1=1.0, b_2=0.5\):
*   Шаг 1 (\(u=1\)): \(y_1 = 0.8\cdot0 + 1.0\cdot1 + 0 = 1.0\).
*   Шаг 2 (\(u=1\)): \(y_2 = 0.8\cdot1.0 + 1.0\cdot1 + 0 = 1.8\).
*   **Тест:** `Model10.ManualSteps`.

### 5.2. Model 2.5 (Нелинейность)
Уравнение: \(y_{t+1} = a y_t + b \cdot \text{sign}(u_t) \cdot (1 - e^{-|u_t|})\).
Проверяется, что при \(u=0\) выход равен 0, при положительном \(u\) — положительный, при отрицательном \(u\) — отрицательный.
*   **Тест:** `Model25.SignBehavior`.

### 5.3. Model DeadZone (Граничные значения)
При \(\delta = 0.2\):
*   Вход \(u = 0.2\) (на границе): \(u_{eff} = 0\).
*   Вход \(u = 0.3\) (выше границы): \(u_{eff} = 0.3 - 0.2 = 0.1\).
*   **Тест:** `ModelDeadZone.BoundaryValues`.

### 5.4. Параметризованные тесты сходимости (TEST_P)
Для проверки сходимости алгоритмов без дублирования кода используется параметризованный тест `ModelConvergenceTest`. Он проверяет, что при подаче ступеньки \(u = const\) линейная модель 1.10 выходит на установившееся значение \(y_{ss} = u \cdot (b_1+b_2)/(1-a_1)\).
*   **Тест:** `Default/ModelConvergenceTest.ConvergesToSteadyState`.
