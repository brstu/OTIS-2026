## 1. Цель работы

Освоить технологию модульного (юнит-) тестирования программ на C++ с применением фреймворка **Google Test**: научиться проверять правильность отдельных единиц кода, строить параметризованные тесты, работать с граничными случаями и измерять тестовое покрытие с помощью утилиты `gcovr`.

## 2. Постановка задачи

Объект тестирования — математическое ядро программы ЛР1 (Модели 1.10, 2.5, 3.10). Требуется:
1. Покрыть программу модульными тестами с помощью Google Test, автоматизировать сборку через CMake.
2. Проверить правильность вычислений моделей на ручных расчетах.
3. Разработать и протестировать модуль анализа устойчивости на Z-плоскости (\(|z| < 1\)).
4. Проверить граничные значения нелинейности (новая модель DeadZone).
5. Проверить физические инварианты (состояние покоя при нулевом входе).
6. Применить параметризованные тесты (`TEST_P`) для проверки сходимости.
7. Отразить количество тестов и процент покрытия в отчете.

## 5. Тестовые сценарии и ручной пересчет

### 5.1. Правильность значений и память модели 1.10
Уравнение: \(y_{t+1} = a_1 y_t + b_1 u_t + b_2 u_{t-2}\).
При \(a_1=0.8, b_1=1.0, b_2=0.5\):
* Шаг 1 (\(u=1\)): \(y_1 = 0.8\cdot0 + 1.0\cdot1 + 0 = 1.0\).
* Шаг 2 (\(u=1\)): \(y_2 = 0.8\cdot1.0 + 1.0\cdot1 + 0 = 1.8\).
* **Тесты:** `Model10.ManualSteps`, `Model10.MemoryTwoSteps`, `Model10.SumOfInputs`. Статус: **PASSED**.

### 5.2. Модуль анализа устойчивости
Характеристическое уравнение для дискретных моделей: \(z - a = 0 \Rightarrow z = a\).
Условие устойчивости: \(|a| < 1\). Для метода Эйлера (Модель 3.10): корень \(z = 1 - a\cdot dt\).
* **Тесты:** `StabilityDiscrete`, `StabilityEuler`, `StabilityWarning`. Статус: **PASSED**.

### 5.3. Граничные значения нелинейности (DeadZone)
При \(\delta = 0.2\):
* Вход \(u = 0.2\) (на границе зоны): эффективный сигнал 0.
* Вход \(u = 0.3\) (выше границы): \(u_{eff} = 0.3 - 0.2 = 0.1\).
* **Тесты:** `ModelDeadZone.BoundaryValues`, `ModelDeadZone.InsideZone`. Статус: **PASSED**.

### 5.4. Физические инварианты и аналитика
* При нулевом входе (\(u=0\)) все системы остаются в покое (\(y=0\)).
* Метод Эйлера (Модель 3.10) сравнен с аналитическим решением затухания \(e^{-at}\).
* **Тесты:** `Models.RestState`, `Model310.EulerVsAnalytic`. Статус: **PASSED**.

### 5.5. Параметризованные тесты и подмена сигналов
* **TEST_P:** `Default/ModelConvergenceTest` проверяет сходимость модели 1.10 к установившемуся значению \(y_{ss}\) на двух наборах параметров.
* **Подмена сигналов:** `SignalModes.ImpulseAndHarmonic` и `SignalModes.ZeroInput` имитируют импульсное, гармоническое и нулевое воздействие. Статус: **PASSED**.
