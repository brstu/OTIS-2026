# Лабораторная работа №2 по ОТИС

Мацуй Никита, группа ИИ-30, №12 по списку (ii03012). Вариант 4. Исследуются три модели из первой лабораторной работы.

| Модель | Расчёт следующего состояния |
| --- | --- |
| 1.4 | `y[k+1] = a y[k] + b (u[k] − u[k−1])` |
| 2.6 | `y[k+1] = a₁ y[k]³ − a₂ y[k−1] + b u[k]²` |
| 3.8 | `y[k+1] = y[k] + Δt (−a₁ y[k] − a₂ y[k]² + b u[k])`, явный метод Эйлера |

В начале каждого опыта симулятор задаёт `y[−1] = y[0] = y₀` и `u[−1] = 0`. Строка CSV с индексом k содержит состояние до применения входа u[k]. Поэтому при n шагах получается n + 1 строка данных. Если очередное значение выходит за предел 10⁶ по модулю или становится неконечным, симулятор завершает опыт на последней допустимой строке.

## Устойчивость модели 1.4

При нулевом входе получаем `y[k+1] = a y[k]`. Подстановка решения вида `zᵏ` даёт характеристическое уравнение `z − a = 0` с единственным корнем `z = a`. Свободный отклик равен `aᵏ y₀`. Коэффициент b влияет на вынужденный отклик.

| Положение корня | Поведение при ненулевом начальном состоянии |
| --- | --- |
| `abs(a) < 1` | Отклик стремится к нулю. Система асимптотически устойчива. |
| `a = 1` или `a = −1` | Модуль отклика постоянен. При −1 знак чередуется. |
| `abs(a) > 1` | Модуль отклика растёт. |

Программа сообщает о корне на границе или за её пределами до вывода таблицы. Проверка фактического расхождения действует во время расчёта для всех трёх моделей.

## Сборка и запуск

Понадобятся CMake 3.21 или новее, компилятор C++17 и Git. При первой сборке CMake загружает Google Test 1.17.0. Для графиков нужны Python 3 и matplotlib.

Собирайте из полной копии репозитория. Базовый класс модели, входные сигналы, модель 2.6 и скрипт графиков подключаются из первой работы. CMake учитывает перенос из ii03004 в ii03012.

В Windows запустите `run_tests.bat` из папки лабораторной. Скрипт настраивает проект, собирает программу и тесты, запускает CTest и сохраняет отчёт JUnit в `build/test-results.xml`. Для Linux и macOS из той же папки выполните:

```sh
cmake -S . -B build
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure --output-junit test-results.xml
```

Для интерактивного запуска перейдите в каталог исполняемого файла `ii03012_task_02` (для Makefiles — `build/src`, для Visual Studio — `build/src/Debug`). Там же лежит `plot.py`. Первый пункт меню запускает девять сочетаний моделей и воздействий. Второй позволяет выбрать модель, коэффициенты, сигнал и начальные условия. CSV и PNG сохраняются в текущем каталоге.
