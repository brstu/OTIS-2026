## 3. Анализ устойчивости Model 1.7

Исходная модель:

\[
y_{k+1}=a y_k+b_1u_k+b_2u_{k-1}+b_3u_{k-2}.
\]

Для анализа свободного движения полагаем вход равным нулю:

\[
y_{k+1}=a y_k.
\]

Подстановка решения \(y_k=z^k\) даёт характеристическое уравнение

\[
z-a=0, \qquad z=a.
\]

Критерий асимптотической устойчивости дискретной системы:

\[
|z|<1 \quad\Longleftrightarrow\quad |a|<1.
\]

Если \(|a|=1\), система находится на границе устойчивости и не является асимптотически устойчивой. Если \(|a|>1\), система неустойчива. Перед симуляцией `main.cpp` проверяет `isStableSystem()` и выводит текст `alertText()` при неустойчивом параметре.

Для Model 2.1 модель нелинейная, поэтому данный линейный критерий к ней напрямую не применяется. Model 3.5 не содержит обратной связи по выходу; модуль корней характеристического уравнения в текущей постановке для неё не требуется.

## 4. Состав модульных тестов

Тесты расположены в `test/`:

- `ModelTests.cpp` — расчётные значения всех моделей, сброс состояния, входные сигналы и фабрика;
- `StabilityTests.cpp` — устойчивый корень, граница \(|z|=1\), неустойчивый корень, некорректные коэффициенты и предупреждение модели;
- `ParameterizedTests.cpp` — `TEST_P` для нескольких наборов коэффициентов и входов Model 1.7, а также для шага Эйлера Model 3.5.

В тестах используются вручную вычисленные ожидаемые значения по формулам моделей. Mock-объекты не требуются: входные сигналы подаются непосредственно в `advance`, что позволяет независимо проверять Step, Impulse и Harmonic.

## 5. Сборка и запуск

### Windows (MinGW)

Запустить из каталога `task_02`:

```bat
run_tests.bat
```

Скрипт конфигурирует CMake, собирает приложение и тесты, запускает `ctest` и сохраняет полный вывод CTest в `test_report.txt`.

### macOS / Linux

```bash
./run_tests.sh
```

Google Test загружается CMake через FetchContent при первой конфигурации, поэтому для первой сборки требуется подключение к интернету.

## 6. Покрытие кода тестами

Для измерения покрытия используется `gcovr` (GCC/Clang):

```bash
python3 -m pip install gcovr
./run_tests.sh
```

Отчёт HTML генерируется в `coverage.html`.
