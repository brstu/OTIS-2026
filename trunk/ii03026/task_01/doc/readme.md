\## Цель работы

Изучить принципы объектно-ориентированного программирования (ООП) на языке C++, реализовать математические модели систем (линейные, нелинейные и дифференциальные уравнения), а также исследовать их поведение при различных типах входных воздействий.



\---



\## Выбранные модели по варианту

Для выполнения лабораторной работы были запрограммированы следующие модели:

1\. \*\*Линейная модель (Блок 1):\*\* `Model 1.1` — стандартная инерционная система первого порядка.

&#x20;  $$\\mathbf{y\_{\\tau+1} = a \\cdot y\_\\tau + b \\cdot u\_\\tau}$$

2\. \*\*Нелинейная модель (Блок 2):\*\* `Model 2.3` — система с нелинейностью типа «зона нечувствительности» (\*Dead-Zone\*).

&#x20;  $$\\mathbf{y\_{\\tau+1} = a \\cdot y\_\\tau + b \\cdot \\text{deadzone}(u\_\\tau)}$$

3\. \*\*Дифференциальное уравнение (Блок 3):\*\* `Model 3.5` — гармоническая управляющая сила, решенная методом Эйлера с шагом дискретизации $\\Delta t$.

&#x20;  $$\\mathbf{\\frac{dy}{dt} = b \\cdot \\sin(u)}$$



\---



\## Архитектура программы (ООП)

Программа написана на языке C++ с соблюдением принципов ООП:

\* Создан \*\*абстрактный базовый класс `Model`\*\*, содержащий чисто виртуальный метод `calculateNextStep()`.

\* Для каждого типа уравнений из варианта созданы \*\*классы-наследники\*\*, переопределяющие логику расчета следующего шага симуляции.

\* Реализована гибкая настройка количества шагов симуляции ($n$).



\---



\## Входные воздействия и результаты

В ходе работы программа протестировала объекты на трех типах сигналов:

1\. \*\*Стуенчатое воздействие\*\* ($u = \\text{const}$)

2\. \*\*Импульсное воздействие\*\* ($u\_0 = 1$, остальные шаги $0$)

3\. \*\*Гармоническое воздействие\*\* ($u = \\sin(\\tau)$)
