# Реализованные модели

## Model 1.9

Трёхшаговая линейная модель:

`y(t+1) = a1*y(t) + a2*y(t-1) + a3*y(t-2) + b1*u(t)`

## Model 2.3

Нелинейная модель с зоной нечувствительности:

`y(k+1) = alpha * y(k) + beta * deadzone(u(k), delta)`

где `deadzone(u, delta)` равна `u - delta` при `u > delta`, `u + delta` при `u < -delta` и `0` в остальных случаях.

## Model 3.7

Дифференциальная модель задаётся уравнением:

`dy/dt = -exp(a) * y + b * u`

Для численного моделирования используется явный метод Эйлера:

`y(k+1) = y(k) + dt * (-exp(a) * y(k) + b * u(k))`

# Входные воздействия

1. Ступенчатое: `u(t) = A`
2. Импульсное: `u(0) = A`, `u(t > 0) = 0`
3. Гармоническое: `u(k) = sin(0.4*k)`

# Функционал


**Программа:**

- реализует базовый абстрактный класс `Model`;
- позволяет использовать три математические модели: `Model1_9`, `Model2_3`, `Model3_7`;
- принимает коэффициенты для каждой модели;
- позволяет задавать начальное значение состояния `y0`;
- принимает входное воздействие `input_signal`;
- для модели `Model1_9` учитывает два предыдущих значения состояния;
- для модели `Model2_3` реализует зону нечувствительности (Deadzone);
- для модели `Model3_7` реализует дискретизацию дифференциального уравнения методом Эйлера;
- вычисляет новое значение состояния на каждом шаге;
- обновляет состояние модели после каждого вычисления;
- позволяет сбрасывать модель к начальному значению с помощью `reset()`;
- использует наследование и виртуальные методы для реализации разных математических моделей.
